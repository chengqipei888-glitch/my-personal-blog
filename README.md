# 澄 · 个人博客

一个简洁、优雅的白色风格中文个人博客，使用 GitHub Pages 发布。

## 网站地址

https://chengqipei888-glitch.github.io/my-personal-blog/

## 页面

- 首页：`index.html`
- 第一篇文章：`posts/first-post.html`

## 发布

仓库默认分支为 `main`，网站文件位于根目录。请在 GitHub 仓库的 **Settings → Pages** 中确认发布来源为 **Deploy from a branch → main → /(root)**。保存后，后续提交会触发网站更新。
